# 模型配置：本机实操陷阱

命令见 [usage.md](usage.md)。本文只记“错在哪、怎么判”，不重复教程。

## 改对文件

- 第三方模型常在 `~/.codex/<profile>.config.toml`，不是默认 `config.toml`。
- `provider-id` 全量替换；`model_catalog_json` 只写设置了 `model=` 的那份。
- `--as-default` 才碰默认配置；`base_url` 为空必 `builder error`。
- `codex --profile` 不可配 `doctor`；目录校验用 `-c model_catalog_json=... debug models`（命令见 [usage.md](usage.md)）。

## 不要猜窗口

- 无官方值用模板默认（`258400` + 五档）或 `--defaults`；`models_cache.json` 只做骨架。
- `slug` 必须与 `model=` 全等；`x-ai/` 前缀也要对上。

## PowerShell / 编码

- `--reasoning-levels` / `--input-modalities` 加引号；`--bootstrap-bundled` 依赖 `codex.cmd`/`codex.exe`。
- 不用 `>` 存 JSON，不用 `text=True` 接 bundled 输出；脚本已按字节 UTF-8 处理。

## 档位与 slug

- `--reasoning-levels` 写目录，`model_reasoning_effort` 写 TOML；只改一处 UI 不会全变。

## 工具字段

- 目录 `input_modalities` 只有 `text`/`image`/`audio`：照抄上游 omni 的 `video` 会让整份 catalog 无法解析（`unknown variant 'video'`），Codex 直接拒绝启动。音频模型加 `audio` 即可。

- `apply_patch=null` → 无 `apply_patch`、无改文件摘要，只能整文件重写；`shell=default`/缺失 → 旧 shell 或拒启动。语义见 [model-catalog-json.md](model-catalog-json.md)，覆盖参数见 [usage.md](usage.md)，三条路与依赖见 [tool-calling.md](tool-calling.md)。
- Grok：`freeform` 实测全失败（`must be '*** Begin Patch'`）则该条改回 `null`（`--apply-patch-type null`，命令见 [usage.md](usage.md)）；`shell` 仍 `unified_exec`，`web_search` 仍 `text`。只动该条。
- `code_mode_only` 会藏起 shell/apply_patch/MCP/skills；注释 catalog 反而正常即是此因。脚本默认去掉它，显式 `--clone-from gpt-6-astra` 才保留。
- 上游拒收 `web_search`（如 mimo-v2.5 起会话即 400）：在该 profile 顶层写 `web_search = "disabled"`（须在 `[table]` 之前），与 `curl` 无关，禁搜索不挡 shell 取 URL。详见 [tool-calling.md](tool-calling.md)。
- 上游拒收 `custom` 工具（如 Xiaomi 网关 `tool type 'custom' is not supported`）：本版 Codex 以 `custom` 类型发 `apply_patch`，该条直接改 `null`（`--apply-patch-type null`），不用试错。改文件改走 shell/Python 整文件重写。定位与验证见 [case-xiaomi-mimo.md](case-xiaomi-mimo.md)。

## verbosity

- 只决定发不发 `text.verbosity`。GPT-5 家族可用；DeepSeek 可传入不生效；Grok 未文档化，保持 `false`/`null`。按各家官方单独设。

## 密钥与提供方

- `env_key` + `models.env`；禁用保留 id；`[model_providers.<id>]` 只在用户级；`wire_api` 只有 `responses`；目录用绝对路径专用文件。

## 安装器与客户端

- 不擅自跑 `curl|bash` / `irm|iex`；三客户端启动时加载，改完重载并开新对话；切提供方后另一组历史仅隐藏。
